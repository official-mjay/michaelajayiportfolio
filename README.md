# Michael Ajayi Portfolio

Professional portfolio for Michael Ajayi — Graphic Designer, Web Designer and Developer.

## Structure
- `index.html` — page structure and portfolio content
- `css/style.css` — complete visual styling and responsive layout
- `js/script.js` — mobile navigation, scroll reveals and dynamic footer year
- `assets/favicon.svg` — site favicon
- `robots.txt` / `sitemap.xml` — basic search-engine setup

The portfolio artwork is embedded directly in `index.html` so the repository can be deployed as a single static site without broken image paths.
